# B3 – Performance experiment notes

Compile benchmark programs with `g++ -std=c++17 -O2 -Wall -Wextra`. They report microseconds from the local machine at run time; timings vary with CPU, compiler, load and optimisation. `main.cpp` compares switch, `std::variant` visitation and a direct-call proxy representing the arithmetic work. For a rigorous virtual-dispatch measurement, use a vector of `unique_ptr<Bill>` populated with both derived classes; do not treat the direct-call proxy as a measured virtual call. The exception benchmark contrasts a status/branch path with throw/catch at 0%, 1%, and 50% invalid rates.

Complexity: all bill-total strategies are O(n) total time and O(n) storage for n records. Each individual dispatch/calculation is O(1). Exception validation is O(n); exception-heavy workloads have higher constant cost as invalid frequency rises. Measurements are generated by executing the included programs on the target machine, not hard-coded.
